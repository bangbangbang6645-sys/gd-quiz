# 🎮 Geometry Dash Boss Trivia (CLI)

A terminal-based trivia application built in Python that tests your knowledge of *Geometry Dash* history, mechanics, and legendary levels. Features 5 progressive questions culminating in a brutal "boss-level" question about iconic community milestones.

---

## 🚀 Features

* **Terminal UI:** Clean, lightweight command-line interface.
* **Progressive Difficulty:** Ranging from basic game mechanics to deep community history.
* **The Ultimate Boss Question:** Do you know the exact verification date of *Bloodbath*?

---

## 🛠️ Requirements

* Python 3.x installed on your machine.
